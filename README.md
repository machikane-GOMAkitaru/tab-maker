# TAB譜メーカー

ブラウザで動くギターTAB譜エディタです。ビルド不要の静的サイト（`index.html` / `style.css` / `app.js`）なので、そのままホスティングできます。

## 機能
- 6弦TAB譜の入力・編集（クリック＋数字キー）
- 音の長さ（全・2分・4分・8分・16分、付点、休符）と、TAB譜下のリズム表示（符尾・連桁・休符記号）
- チューニング設定（標準・ドロップD・半音下げ等のプリセット＋弦ごとのカスタム）。左端の弦名と冒頭の「⑥=D」表記に反映
- Web Audio API の撥弦合成によるデモ再生（テンポ、ループ、メトロノーム、再生位置のハイライト）
- PDF出力（印刷用レイアウト。曲名・テンポ・チューニングを表記）
- localStorage への自動保存、JSON 書き出し・読み込み

## 公開方法

### GitHub Pages
1. このフォルダの中身をリポジトリのルートに push
2. GitHub の Settings → Pages → Source を「Deploy from a branch」、ブランチを `main` / `/ (root)` に設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### Cloudflare Pages
1. Cloudflare ダッシュボード → Workers & Pages → Create → Pages
2. GitHub リポジトリを接続（または「Upload assets」でフォルダをドラッグ＆ドロップ）
3. ビルドコマンドは空欄、出力ディレクトリは `/` のままでデプロイ

## ローカルで試す
`index.html` をブラウザで直接開いても動きます。ローカルサーバーで開く場合:

```bash
python -m http.server 8000
```

## データ形式（JSON）
```json
{
  "version": 2, "title": "曲名", "artist": "", "tempo": 100, "beats": 4,
  "tuning": [64, 59, 55, 50, 45, 38],
  "measures": [[ { "d": 8, "dot": false, "n": ["", "", "", "0", "0", "0"] } ]]
}
```
- `tuning` は1弦→6弦の MIDI ノート番号
- `d` は音価（1=全音符, 2, 4, 8, 16）、`n` は1弦→6弦のフレット（全部空なら休符）、`ps: true` でピックスクラッチ
- `tone` は再生の音色（`"clean"` / `"dist"`）

フレットの書式: `[(]` `[/]` フレット `[)]` 奏法

| 書き方 | 意味 |
|---|---|
| `(7)` | タイ（前の音をのばす） |
| `/7` | スライドイン |
| `7b` / `7u` | チョーキング 全音 / 半音 |
| `7r` / `7br` | 戻し（プリベンド＆リリース / チョーキング＆リリース） |
| `7~` / `7b~` | ビブラート / チョーキングしてからビブラート |
| `0w` | アーム・ダウン（w/bar） |
| `4a` | ピッキング・ハーモニクス（P.H.） |
| `5h` `7p` `5/` `7\` | ハンマリング / プリング / スライド（次の音がなければスライドアウト） |
| `x` | ブラッシング（ミュート音） |

更新時は `index.html` の `style.css?v=` と `app.js?v=` の番号を上げてください（ブラウザに古いファイルを使わせないため）。
